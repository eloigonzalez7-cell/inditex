# Definition of Done

A story is **Done** when all applicable items are checked:

- [ ] Behaviour matches acceptance criteria in [BACKLOG.md](BACKLOG.md)
- [ ] TypeScript strict; no `any` without justification
- [ ] Hexagonal boundaries respected (UI → use cases → ports)
- [ ] Native CSS only
- [ ] Unit tests added/updated for touched domain or application logic
- [ ] E2E updated if a user journey changed
- [ ] Errors logged to console with message and stack
- [ ] Conventional Commit message in English
- [ ] Backlog status updated
- [ ] README/docs updated when scripts or setup change
